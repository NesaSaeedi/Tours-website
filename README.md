## 🌍 About The Project

Travel is more than just visiting a destination — it's about discovering new experiences, exploring different cultures, and creating memories that last a lifetime.

This project is a front-end tourism website designed to present travel destinations in an attractive and organized way. The interface combines beautiful imagery with a clean layout to create an immersive travel-focused experience.

The main goal of this project was to practice modern web design principles while creating a website that feels **professional, elegant, and engaging**.

## 🎨 Design

The design of the website focuses on creating a strong visual connection with travel.
